# Titanic Dataset - Exploratory Data Analysis (EDA)

## 📌 Task Overview
This project was completed as part of my **Data Analyst Internship**.  
**Task 5: Exploratory Data Analysis (EDA)**  
The objective was to extract insights from the Titanic dataset using **statistical and visual exploration techniques**.

## 🛠 Tools & Libraries
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Jupyter Notebook  
- ReportLab (for PDF report generation)

## 📂 Files in this Repository
- `Titanic_EDA.ipynb` → Jupyter Notebook containing code, visualizations, and step-by-step analysis.  
- `Titanic_EDA_Report.pdf` → PDF report summarizing findings and insights with structured explanation.  
- `train.csv` & `test.csv` → Datasets used for analysis (Kaggle Titanic dataset).  

## 🔍 Exploratory Steps
1. **Data Overview**: Inspected structure, missing values, and descriptive statistics.  
2. **Univariate Analysis**: Histograms and count plots for Age, Fare, Sex, Pclass, Embarked.  
3. **Bivariate Analysis**: Survival relationships with Age, Fare, Sex, Pclass, and Embarked.  
4. **Correlation Analysis**: Heatmap of numerical features.  
5. **Pairwise Relationships**: Pairplot to identify feature interactions.  

## 📊 Key Insights
- **Gender**: Females had much higher survival rates than males.  
- **Class**: First-class passengers survived at a higher rate than lower-class passengers.  
- **Age**: Children had better survival chances compared to adults.  
- **Fare**: Higher fare passengers were more likely to survive.  
- **Embarked**: Passengers from port 'C' survived slightly more compared to 'S'.  

## 📝 Conclusion
The EDA highlights that **socioeconomic and demographic factors (gender, class, fare, age)** had a significant impact on survival.  
Women, children, and wealthier passengers had the highest chances of survival.
